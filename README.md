# MakeMyTrip Booking Cancellation & Guest Issue Analyzer

## Overview
This project analyzes hotel booking cancellations, guest complaints, and refund requests to identify operational bottlenecks and improve the overall customer experience. It processes multiple data formats (CSV, JSON, Excel) to provide actionable insights for a hospitality platform.

## Features
- **Booking Analysis:** Tracks booking trends and correlates cancellations with different hotel types.
- **Complaint Resolution Tracking:** Analyzes guest complaints and support tickets to measure resolution times.
- **Refund Processing Metrics:** Evaluates refund request statuses and financial impact.
- **Data Integration:** Combines structured data (CSV, Excel) and semi-structured data (JSON) into a unified analysis pipeline.

## Dataset Structure
The analysis relies on the following datasets included in this repository:
- `hotel_bookings.csv` - Core booking records
- `cancellations.xlsx` - Detailed cancellation logs
- `guest_complaints.json` - Structured feedback and complaints
- `refund_requests.xlsx` - Financial refund tracking
- `support_tickets.csv` - Customer service interaction logs
- `customers.csv` - Customer demographic data
- `hotels.csv` - Hotel property details
- `operations_notes.txt` - Unstructured operational logs
